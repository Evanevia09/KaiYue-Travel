## Recommendation (delivered to owner 20:26)

Use a dedicated staff account with a small direct HTTP client: sign in with email and password, keep the cookie jar in memory, and send `Origin` on writes. Re-authenticate once on 401. Use idempotency keys for creates and `expectedUpdatedAt` for edits and assignment, re-reading on 409. Send full-replacement edit bodies. Poll with `updatedSince` plus `nextCursor`. A thin MCP adapter only if the agent host requires it. Contract: `docs/api/admin-agent-v1.openapi.yaml`; guide: `docs/13-agent-api.md`.

## Known residuals (documented, not fixed)
